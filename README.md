# Conductor

A fast, low-friction sketch tool for power systems projects. Rough out a one-line in minutes, then keep adding detail to the same objects from design through commissioning and operations.

Every item on the single-line diagram (SLD) is a real object. It has a stable ID, typed terminals, connections, and properties grouped by lifecycle phase.

```
npm install
npm run dev     # http://localhost:5180
npm test
npm run build
```

Local-first: projects autosave in your browser. Use **Settings → Export JSON** to keep a copy.

See `CLAUDE.md` for architecture and conventions, `docs/DECISIONS.md` for decisions, and `CHANGELOG.md` for versions.
